Jack

Polar Bears Past Bedtime · Magic Tree House #12

MTH-JACK · 4권 얼굴·체형 참조 연결 / 12권 전용 이미지 생성 대기

원문에 명시된 특징·사건

  • 원문: 잠옷을 입고 운동화를 신어 출발한다. 손전등·배낭·노트·책을 사용한다.
  • 3장: 후드 파카 → 모피 바지 → 부츠·벙어리장갑 순서로 착용한다. 배낭 끈을 늘려 파카 위로 멘다.
  • 6장: 안경을 벗고 나무 북극곰 가면을 쓴다. 7장: 가면을 벗고 안경을 다시 쓴다.
  • 9장: 방한복과 부츠를 돌려주어 잠옷·맨발 상태가 된다. 10장: 얇은 나무 도서관 카드를 받는다.

계승 기준·제작 선택

  • 시리즈 기준: 8½세, 짧고 헝클어진 갈색 머리, 큰 원형 안경, Annie보다 조금 큰 체형. 4권 시트의 얼굴과 비율을 유지한다.
  • 12권 제작 선택: 잠옷은 탁한 파랑, 배낭은 갈색. 원문이 색을 정한 것은 아니다.
  • 12권 방한복: 짙은 갈색 가죽 파카와 밝은 털 테두리, 갈색 모피 바지·부츠·장갑.

전용 이미지 시트 구성

  • 얼굴 정면·측면·¾ / 걱정·관찰·기쁨
  • 잠옷+운동화 / 방한복 / 잠옷+맨발 전신
  • 가면 착용과 안경 보관 / 얼음 위 엎드려 미끄러지기

크림 종이 바탕, 명료한 갈색 윤곽선, 부드러운 셀 음영. 인물 정면·¾·측면, 표정, 전신 비율과 소품을 검수합니다.

장면 생성 시 금지·주의

  • 4권의 빨간 평상복이나 노란 우비를 12권 기본 의상으로 복사하지 않는다.
  • 가면 착용 중 안경을 얼굴 위에 겹치지 않는다. 실제 곰 변신·날개를 그리지 않는다.
